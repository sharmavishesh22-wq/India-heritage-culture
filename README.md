# 🇮🇳 India's Heritage and Culture

An interactive web prototype showcasing India's rich heritage, culture, traditions, food, arts, crafts, festivals, and historical diversity.

## 🎯 About the Project

India is home to diverse cultures, traditions, languages, festivals, art forms, and heritage sites. This project aims to provide an engaging digital platform where users can explore the cultural richness of different states of India.

This project was developed as a prototype for the **Smart India Hackathon (SIH) Internal Round**.

## ✨ Features

- 🗺️ Interactive India Map
- 🏛️ State-wise Heritage Information
- 🍛 Famous Food and Cuisine
- 🎉 Festivals and Traditions
- 💃 Dance and Cultural Forms
- 🎨 Arts and Crafts
- 📸 State-specific Visual Content
- ✨ Interactive and Animated User Interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Netlify for Deployment
